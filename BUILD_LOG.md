**Built**

- Docs: README, USAGE, MIGRATION, TEST_REPORT; COPYING (GPL-3), MANIFEST, CHANGELOG.

**Deviations from the approved design, and why**
- Added shapes `GAIN_LIMITED`, `BELOW_CLIFF`, `BLIND_DIAL`; dropped
  `OVERLOAD_STAIRCASE` as a verdict (the staircase is handled by the search, which
  extends the span, and reported in the log).
- "Thermal-limited" and "aperture-limited" cannot be told apart from behind the
  LNA, so both are `APERTURE_LIMITED`, worded as "the limit is ahead of the radio's
  gain stages". `GAIN_LIMITED` is the distinguishable case: still rising at max gain.
- gr-soapy `setting` commands are refused by default (hardware finding).
- Message mode counts as closed-loop when a Message Setter's readback covers every
  searched knob.
- Dashboard import is lazy so that importing `gnuradio.rxtune` never imports Qt.

- gr-soapy per-element gain BY MESSAGE works on the RSPdx. `RFGR` == `rfgain_sel`, 0-27.
- NRSC-5 hardware run: HEALTHY, 12.9 dB, decoding, stream 1.000.
